# Preview Project Workflow

This workflow details the steps required to start the local development and preview server for the Next.js project.

## Steps

### Step 1: Start the Development Server
Run this command in the project root to start the Next.js development server:
```bash
npm run dev
```
This executes `next dev --turbopack -p 9002` which hosts the project locally.

### Step 2: Access the Application
Once the server starts successfully, open your web browser and navigate to:
```
http://localhost:9002
```
This will allow you to preview and interact with the application.
